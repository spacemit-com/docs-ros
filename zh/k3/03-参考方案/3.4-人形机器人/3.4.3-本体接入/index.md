# 本体接入

本章说明如何把机器人模型、关节、执行器、传感器和整机硬件后端接入人形 SDK，并将差异收敛在独立机型包中。

| 内容 | 说明 |
| --- | --- |
| [机器人模型与关节映射](3.4.3.1-机器人模型与关节映射.md) | 建立模型自由度、SDK 关节顺序与物理执行器之间的映射 |
| [执行器与传感器接入](3.4.3.2-执行器与传感器接入.md) | 接入电机、IMU 等设备并统一状态和指令单位 |
| [整机控制与硬件后端](3.4.3.3-整机控制与硬件后端.md) | 理解 `whole_body` 的硬件抽象、配置与安全边界 |
| [新增机型](3.4.3.4-新增机型.md) | 按 SDK 责任边界创建机型包、target 和验证入口 |
| [实机启动与标定](3.4.3.5-实机启动与标定.md) | 在闭环控制前完成零位、方向、限位、通信和安全检查 |

开始前应先了解[SDK 架构](../3.4.2-开发基础/3.4.2.2-SDK架构.md)和[机型包与配置](../3.4.2-开发基础/3.4.2.4-机型包与配置.md)。
