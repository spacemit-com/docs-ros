# 本体接入

本章说明如何把机器人模型、关节、执行器、传感器和整机硬件后端接入人形 SDK，并将差异收敛在独立机型包中。

| 内容 | 说明 |
| --- | --- |
| 机器人模型与关节映射 | 建立模型自由度、SDK 关节顺序与物理执行器之间的映射，文档整理中 |
| 电机与 IMU 接入 | 接入运控设备并统一状态、指令和时间语义，文档整理中 |
| [整机控制与硬件后端](3.4.3.3-整机控制与硬件后端.md) | 理解 `whole_body` 的硬件抽象、配置与安全边界 |
| 新增机型 | 按 SDK 责任边界创建机型包、target 和验证入口，文档整理中 |
| 实机启动与标定 | 在闭环控制前完成零位、方向、限位、通信和安全检查，文档整理中 |
| 相机与激光雷达接入 | RGB/RGB-D 相机、激光雷达驱动、ROS 2 数据接口、时间同步与标定，文档整理中 |

开始前应先了解[SDK 架构](../3.4.2-开发基础/3.4.2.2-SDK架构.md)和[机型包与配置](../3.4.2-开发基础/3.4.2.4-机型包与配置.md)。
