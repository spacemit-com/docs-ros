# Robot-Skills 与 Agent

本节定义人形机器人技能如何封装为可发现、可校验、可执行和可反馈的能力，并说明 Agent 如何调用这些技能。通用 Agent、MCP 和设备工具接入方式见 [Agent](/k3/ai/agent)与[语音控制](/k3/ai/voice-control)文档。

## 技能模型

每项技能需要说明名称、用途、输入参数、适用状态、执行结果、取消方式和失败原因。技能接口面向行为能力，不暴露关节级控制细节，也不把单个演示脚本直接等同于可复用技能。

## Agent 工具映射

Agent 工具调用需要映射到明确的机器人技能，并在执行前完成参数校验、权限检查和状态检查。工具调用返回值应保留机器人侧的执行状态和失败原因。

## 安全与执行反馈

高风险运动需要确认、限权或禁止由开放式生成结果直接触发。取消、超时、安全停止和人工接管应能从机器人运行时反馈到技能层和 Agent。
