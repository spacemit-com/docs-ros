# 仿真问题

| 现象 | 处理 |
| --- | --- |
| `[MujocoConfig] MuJoCo XML 文件不存在: ...` | YAML 中 `robot_base.robot_dir` 指向的目录下缺少 `resources/xml/scene.xml`。检查路径和文件是否存在。 |
| 仿真启动后没有状态或控制数据 | 先按[运行时与通信问题](3.4.10.3-运行时与通信问题.md)检查进程和通信，再确认 driver 与 control 使用同一份机型配置。 |
| 进入 RL 后姿态异常或立即摔倒 | 先按[配置与策略问题](3.4.10.2-配置与策略问题.md)核对自由度、关节顺序、默认姿态和策略输入输出。 |

排查仿真结果时，需要区分模型加载成功、通信链路建立、控制闭环运行和动作效果达标四个阶段。
