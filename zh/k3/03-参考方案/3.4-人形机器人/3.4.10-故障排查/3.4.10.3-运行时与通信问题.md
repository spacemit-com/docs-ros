# 运行时与通信问题

| 现象 | 处理 |
| --- | --- |
| `driver_runtime` 未生成或提示 backend 未编译 | 当前 target 没有提供可用的 MuJoCo / `whole_body` backend，或 YAML 的 `driver.backend` 选择了未编入的 backend。检查 target 的 `enabled_backends`、组件构建产物和 YAML。 |
| 进程启动后通信无数据 | UDP：检查 `driver_ip`、`control_ip`，确认两机可互相 `ping` 通，并检查防火墙是否放行 8800～8802 端口。SHM：运行 `ls /dev/shm/hmrs_*`，确认共享内存文件已经创建。 |
| `[Udp] bind 失败, ip=... port=...` | 端口被占用或 IP 不存在。运行 `ss -ulnp \| grep 880` 检查端口占用，并确认 YAML 中填写的是本机实际 IP。 |

跨机问题应分别保存 PC 与 K3 两端日志，并确认日志中的监听地址、目标地址和端口与实际部署拓扑一致。
