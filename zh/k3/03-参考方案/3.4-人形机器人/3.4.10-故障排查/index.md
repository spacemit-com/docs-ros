# 故障排查

本章按问题所在环节组织人形方案的排查方法。记录问题时，应同时保留启动命令、完整日志、机型 YAML、策略名称、通信模式和两端 IP。

| 问题类型 | 阅读入口 |
| --- | --- |
| YAML、模型加载、关节映射或策略控制异常 | [配置与策略问题](3.4.10.2-配置与策略问题.md) |
| 运行进程、硬件后端或进程间通信异常 | [运行时与通信问题](3.4.10.3-运行时与通信问题.md) |
| MuJoCo 模型、启动或闭环仿真异常 | [仿真问题](3.4.10.4-仿真问题.md) |

排查时先确认问题能否稳定复现，再从日志中定位首次异常，避免只依据机器人最终姿态判断原因。
