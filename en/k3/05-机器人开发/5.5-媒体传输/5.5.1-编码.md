# Media Transmission · Encoding

## 1. Overview

- **Key Features**: Video encoding module that compresses raw YUV/RGB video frames into H.264/H.265/JPEG bitstreams for network transmission or storage, significantly reducing bandwidth and storage requirements.
- **Specifications and Features**:
  - Supported encoding formats: H.264 (AVC), H.265 (HEVC), MJPEG
  - Supported resolutions: up to 4K (3840x2160)
  - Supported frame rates: up to 30fps (1080p), 60fps (720p)
  - Bitrate control: CBR (Constant Bitrate), VBR (Variable Bitrate)
  - Hardware acceleration: uses hardware encoder for low power consumption and high performance
- **Directory Structure**: Based on the MPP framework, see [Multimedia · MPP](../../06-系统与平台/6.3-多媒体/6.3.1-mpp.md)

## 3. Example Usage (From Scratch)

### 3.1 Command-Line Encoding Test (File to File)

Use the MPP built-in `test_venc_file` tool to encode raw YUV frames into H.264/H.265 bitstreams and quickly verify encoding functionality.

**Prerequisites**: MPP compiled, development board powered on and accessible via SSH

**Step 1**: SSH into the development board

```bash
ssh root@<Board_IP>
# Password: root
```

**Step 2**: Navigate to the SDK build directory, copy related test files, then enter the test program directory

```bash
cd spacemit_robot
cp components/multimedia/mpp/test/assets/vi_phy0_last_frame.yuv output/build/cmake/pkgs/components_multimedia_mpp/test/
cd output/build/cmake/pkgs/components_multimedia_mpp/test
```

**Step 3**: Run H.264 encoding

```bash
./test_venc_file ./vi_phy0_last_frame.yuv 1920 1080 ./enc_out.h264 h264 1
```

Parameter description:

| Parameter | Description |
| --- | --- |
| `./vi_phy0_last_frame.yuv` | Input YUV (NV12) file path |
| `1920` | Image width |
| `1080` | Image height |
| `./enc_out.h264` | Output bitstream file path |
| `h264` | Encoding format (supports `h264`, `h265`) |
| `1` | Number of frames to encode |

Expected output:

```text
[INFO] VENC file test: ./vi_phy0_last_frame.yuv 1920x1080 -> ./enc_out.h264 (H.264), frames=1
[INFO] encoded frame 0: size=63778 key=0 pts=0
[INFO] done, encoded 1 frame(s)
```

After encoding completes, the `enc_out.h264` file is generated in the current directory.

**Step 4**: Verify output bitstream

Copy `enc_out.h264` to a PC and use `ffplay` to verify playback:

```bash
ffplay enc_out.h264
```

### 3.2 H.264 Encoding API Example

The following code example demonstrates the core calling flow using the MPP API for encoding.

**Step 1**: Create encoder context

```c
#include "venc.h"

MppVencCtx *ctx = venc_ctx_create();
venc_ctx_init(ctx);
```

**Step 2**: Set encoding parameters

```c
MppVencPara para;
para.eCodecType = MPP_CODEC_H264;
para.u32Width = 1920;
para.u32Height = 1080;
para.u32Fps = 30;
para.u32Bitrate = 4000000; // 4Mbps
venc_ctx_set_param(ctx, VENC_CMD_SET_PARA, &para);
```

**Step 3**: Submit raw frame and encode

```c
MppData input_frame;
// Populate input_frame data
venc_ctx_encode(ctx, &input_frame);
```

**Step 4**: Retrieve encoded bitstream

```c
MppData output_stream;
venc_ctx_get_output_stream(ctx, &output_stream);
// Process output_stream (save or send)
venc_ctx_return_output_stream(ctx, &output_stream);
```

Expected result: Output H.264 bitstream, verifiable with a player

## 4. Application Development

- **API / Interface**:

  - Header file: `include/venc.h`
  - Library name: `libmpp_venc.so`
  - Main APIs:
    - `venc_ctx_create()` - Create encoder context
    - `venc_ctx_init()` - Initialize encoder
    - `venc_ctx_set_param()` - Set encoding parameters
    - `venc_ctx_encode()` - Encode one frame
    - `venc_ctx_get_output_stream()` - Get output bitstream
    - `venc_ctx_destroy()` - Destroy encoder
- **Usage and Notes**:

  - Initialization sequence: create → init → set_param → encode
  - Thread safety: Single context does not support multi-threaded concurrent access
  - Memory management: Input frames must use MPP memory allocation interface
  - Bitstream release: After retrieving bitstream, must call `return_output_stream()` to release
  - Parameter adjustment: Bitrate, frame rate, and other parameters can be dynamically adjusted at runtime
- **Reference Demo / Example Path**: `mpp/test/test_venc_file.c`, `mpp/mpi/venc/venc_api.c`, `mpp/sample/`

## 5. Debugging Guide

- **Bitstream verification**: Use `ffplay` or `vlc` to play output bitstream and verify correctness
- **Performance analysis**: Record encoding time, calculate actual frame rate and bitrate
- **Quality tuning**: Adjust QP parameters and bitrate control mode to optimize image quality

## 6. Common Issues

| Symptom | Possible Cause | Resolution |
| --- | --- | --- |
| Encoder initialization failed | Hardware encoder plugin not loaded | Check if libv4l2_linlonv5v7_codec2.so exists |
| Low encoding frame rate | Input frame rate too high or resolution too large | Reduce resolution or frame rate |
| Bitstream cannot be played | Incorrect encoding parameters or corrupted bitstream | Check encoding parameters, use standard test frames |
| Poor image quality | Bitrate too low | Increase target bitrate |
