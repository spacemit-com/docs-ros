The following example demonstrates how to build and run visual object detection.

### 2.1 One-Command Build

```bash
cd components/model_zoo/vision
mm
```

### 2.2 Quick Start

Download the model assets:

```bash
bash examples/yolov8/scripts/download_models.sh

bash scripts/download_assets.sh
```

Run object detection:

```bash
yolov8 examples/yolov8/config/yolov8.yaml
```

Optional: Use a camera for real-time detection:

```bash
yolov8 examples/yolov8/config/yolov8.yaml --use-camera --camera-id 0  # Confirm the camera ID
```

## 3. Voice Interaction

This section uses Omni Agent as an example to demonstrate how to build and run voice interaction.

### 3.1 One-Command Build

```bash
cd <project-root>
lunch
```

Select a build target:

```text
You're building on Linux

Lunch menu... pick a combo:

     1  k1-muse-pipro-minimal
     2  k3-com260-kit-humanoid-asimov
     3  k3-com260-kit-humanoid-qinglong
     4  k3-com260-kit-humanoid-tiangong
     5  k3-com260-kit-humanoid-tinker
     6  k3-com260-kit-humanoid-unitree-g1
     7  k3-com260-kit-humanoid-unitree-go1
     8  k3-com260-kit-humanoid-unitree-h1_2
     9  k3-com260-kit-humanoid-unitree-r1
     10  k3-com260-linksee
     11  k3-com260-minimal
     12  k3-com260-reachy-mini
     13  kx-generic-omni_agent
```

Select `kx-generic-omni_agent`, then build:

```bash
m  # One-command build
```

### 3.2 Quick Start

Download the model assets:

```bash
mkdir -p ~/.cache/models/llm
cd ~/.cache/models/llm
# Example: Download the qwen2.5 0.5b model
wget https://archive.spacemit.com/spacemit-ai/model_zoo/llm/qwen2.5-0.5b-instruct-q4_0.gguf
```

Start the LLM service:

```bash
 llama-server -m ~/.cache/models/llm/qwen2.5-0.5b-instruct-q4_0.gguf -t 8 --port 8080
```

Start voice interaction:

```bash
voice_chat --llm-url http://localhost:8080 --model qwen2.5:7b --tts matcha:zh-en
```
