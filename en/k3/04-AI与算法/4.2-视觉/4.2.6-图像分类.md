# Vision · Image Classification

## 1. Overview

- **Key Features**: ResNet50-based image classification. Given an image, the model returns Top-K class predictions and confidence scores. It supports 1,000 ImageNet classes.
- Specifications and features:
    - Supported model: ResNet50
    - Input size: `[1, 3, 224, 224]`
    - Quantization: int8
    - Output: Top-K class IDs and confidence scores
    - Inference backend: ONNX Runtime + SpaceMITExecutionProvider
    - Interfaces: C++ (`vision_service.h`), Python (`spacemit_vision` wheel: `VisionServiceNative`)
- Related directory structure:

```
examples/resnet/
├── config/resnet50.yaml   # Configuration file
├── cpp/resnet.cpp         # C++ example
├── python/resnet.py       # Python example
└── scripts/               # Model download scripts
src/deploy/resnet/         # Deployment implementation (C++ / Python)
assets/labels/imagenet.txt # Labels for the 1,000 ImageNet classes
```

```bash
cd components/model_zoo/vision
```

Model weights are stored by default under `~/.cache/models/vision/resnet/`. You must run the download script manually first; if the model is missing, the program fails immediately with a `Model file not found` error.

## 4. Application Development

This chapter is for application developers and explains how to integrate the image-classification component into your own C++ or Python applications. The complete interface definitions are in `include/vision_service.h` and `src/python/spacemit_vision/vision_service_native.py`; this section covers the commonly used public APIs and typical usage patterns.

### 4.1 Interface Reference

The core entry points of the image-classification component are `VisionService` (C++) and `VisionServiceNative` (Python, `spacemit_vision` wheel). Applications use these interfaces to load the ResNet model and issue image-classification requests.

#### 4.1.1 Common Data Structures

| Type | Description |
| --- | --- |
| VisionServiceResponse | Inference response. `results` is a `vision::ResultList` (`std::vector<vision::Result>`, variant); each element is a `vision::Classification` for a classification task. `ok` indicates whether the operation succeeded, and `error_message` contains the error message. |
| vision::Classification | Classification result containing the class ID (`label`), confidence score (`score`), and probabilities for all classes (`class_scores`). |

#### 4.1.2 Service Initialization

**C++ API**

| API | Description | Parameters | Return Value |
| --- | --- | --- | --- |
| VisionService::Create | Creates a classification service instance from a YAML config file | config_path: path to the YAML config file | Smart pointer to a VisionService |
| VisionService::LastCreateError | Gets the error message from the most recent failed creation attempt | None | Error description string |

**Python API**

| API | Description | Parameters | Return Value |
| --- | --- | --- | --- |
| VisionServiceNative.create | Creates a service instance from a YAML configuration file | config_path: YAML path; model_path_override: optional model-path override | VisionServiceNative instance |
| VisionServiceNative.last_create_error | Gets the error message from the most recent failed creation attempt | None | Error description string |

#### 4.1.3 Image Classification

**C++ API**

| API | Description | Parameters | Return Value |
| --- | --- | --- | --- |
| Infer | Classifies an image file | image_path: image-file path; response: output response; params: optional inference parameters | VisionServiceStatus (`VISION_SERVICE_OK` indicates success) |
| Infer | Classifies a `cv::Mat` image | image: OpenCV Mat object; response: output response; params: optional inference parameters | VisionServiceStatus (`VISION_SERVICE_OK` indicates success) |
| GetClassNames | Gets the class-name table loaded from the configuration; use the label as the index to retrieve a class name | None | Vector of class-name strings |
| LastError | Gets the error message from the most recent inference | None | Error description string |

Use the following accessors to read classification results: `vision::get_label(result)` returns the class ID, and `vision::get_score(result)` returns the confidence score. To obtain the probabilities for all classes, use `const vision::Classification* cls = std::get_if<vision::Classification>(&result);` and then read `cls->class_scores`.

**Python API**

| API | Description | Parameters | Return Value |
| --- | --- | --- | --- |
| infer_image | Classifies an image | image_or_path: BGR NumPy array or image path | (VisionServiceStatus, results list; read `results[0].class_scores` to obtain the probability for each class) |
| get_class_names | Gets the class-name list from the configuration | None | List of strings |
| last_error | Gets the error from the most recent inference | None | Error description string |

#### 4.1.4 Performance Monitoring

**C++ API**

| API | Description | Parameters | Return Value |
| --- | --- | --- | --- |
| SetTimingOptions | Enables or disables performance timing | options: VisionServiceTimingOptions (`enabled`, `print_to_stdout`) | void |
| GetLastTiming | Gets the duration of each stage of the most recent inference | None | VisionServiceTiming structure (`preprocess_ms`, `model_infer_ms`, `postprocess_ms`, `infer_ms`) |

### 4.2 Typical Calling Patterns

#### 4.2.1 Single-Image Classification in C++

```cpp
#include "vision_service.h"
#include <opencv2/opencv.hpp>
#include <iostream>

int main() {
    // 1. Create the service
    auto service = VisionService::Create("examples/resnet/config/resnet50.yaml");
    if (!service) {
        std::cerr << "Failed to create service: " 
                  << VisionService::LastCreateError() << std::endl;
        return -1;
    }

    // 2. Enable performance timing (optional)
    VisionServiceTimingOptions timing_options;
    timing_options.enabled = true;
    service->SetTimingOptions(timing_options);

    // 3. Run inference
    VisionServiceResponse response;
    VisionServiceStatus ret = service->Infer("test.jpg", &response);
    if (ret != VISION_SERVICE_OK) {
        std::cerr << "Inference failed: " << service->LastError() << std::endl;
        return -1;
    }

    // 4. Process the results (Top-5)
    std::cout << "Classification results (Top-5):" << std::endl;
    const size_t max_results = std::min<size_t>(response.results.size(), 5);
    for (size_t i = 0; i < max_results; ++i) {
        std::cout << "  " << (i + 1) << ". Class "
                  << vision::get_label(response.results[i])
                  << ", Confidence: " << vision::get_score(response.results[i])
                  << std::endl;
    }

    // 5. View performance metrics (optional)
    VisionServiceTiming timing = service->GetLastTiming();
    std::cout << "Preprocess: " << timing.preprocess_ms << " ms" << std::endl;
    std::cout << "Inference: " << timing.model_infer_ms << " ms" << std::endl;
    std::cout << "Postprocess: " << timing.postprocess_ms << " ms" << std::endl;

    return 0;
}
```

#### 4.2.2 Batch Image Classification in C++

```cpp
#include "vision_service.h"
#include <opencv2/opencv.hpp>
#include <algorithm>
#include <iostream>
#include <filesystem>

int main() {
    auto service = VisionService::Create("examples/resnet/config/resnet50.yaml");
    
    // Iterate over all images in the directory
    for (const auto& entry : std::filesystem::directory_iterator("images/")) {
        if (entry.path().extension() == ".jpg") {
            VisionServiceResponse response;
            service->Infer(entry.path().string(), &response);

            // Print the Top-1 result
            if (!response.results.empty()) {
                const auto& top1 = *std::max_element(
                    response.results.begin(), response.results.end(),
                    [](const auto& a, const auto& b) {
                        return vision::get_score(a) < vision::get_score(b);
                    });
                std::cout << entry.path().filename() << ": Class "
                          << vision::get_label(top1) << " ("
                          << vision::get_score(top1) << ")" << std::endl;
            }
        }
    }

    return 0;
}
```

#### 4.2.3 Single-Image Classification in Python

```python
import cv2
from spacemit_vision import VisionServiceNative, VisionServiceStatus

svc = VisionServiceNative.create("examples/resnet/config/resnet50.yaml")
image = cv2.imread("test.jpg")

status, results = svc.infer_image(image)
if status != VisionServiceStatus.OK:
    raise RuntimeError(svc.last_error())

scores = list(results[0].class_scores)
order = sorted(range(len(scores)), key=lambda i: scores[i], reverse=True)[:5]
print("Top-5:")
for rank, i in enumerate(order, 1):
    print(f"  {rank}. Class {i} ({scores[i]:.4f})")
```

#### 4.2.4 Batch Image Classification in Python

```python
import glob
import cv2
from spacemit_vision import VisionServiceNative, VisionServiceStatus

svc = VisionServiceNative.create("examples/resnet/config/resnet50.yaml")

for path in glob.glob("images/*.jpg"):
    image = cv2.imread(path)
    status, results = svc.infer_image(image)
    if status != VisionServiceStatus.OK:
        continue
    scores = list(results[0].class_scores)
    top = max(range(len(scores)), key=lambda i: scores[i])
    print(f"{path}: Class {top} ({scores[top]:.4f})")
```

### 4.3 Configuration Reference

The YAML configuration file defines the model-loading and inference parameters. The following example describes all configuration items:

```yaml
# Model file path (ResNet50 ImageNet classification model)
model_path: ~/.cache/models/vision/resnet/resnet50.q.onnx

# Test image path (used by the example program)
test_image: ~/.cache/assets/image/005_kitten.jpg

# Class-label file path (1,000 ImageNet classes)
label_file_path: assets/labels/imagenet.txt

# Model input size [height, width] (the standard ResNet input is 224×224)
image_size: [224, 224]

# Deployment class name (the C++ model-factory registration name; Python uses it indirectly through the YAML path)
class: deploy.resnet.ResNetClassifier

# Inference parameters
default_params:
  # Number of inference threads (the example default is 8; 8 is the recommended intra-op maximum on K3 and can be reduced as needed)
  num_threads: 8
  
  # Inference backends (SpaceMITExecutionProvider is preferred)
  providers:
    - SpaceMITExecutionProvider
    - CPUExecutionProvider  # Fallback backend
```

**Parameter tuning recommendations**:

- **image_size**: The standard ResNet input is [224, 224]. Changing it is not recommended.
- **num_threads**: The example YAML defaults to 8. The **recommended maximum** number of intra-op threads on K3 is 8. If CPU contention occurs or latency is unstable, try reducing this value to 4. Values above 8 are not recommended.
- **providers**: Use SpaceMITExecutionProvider first for the best performance.
- **label_file_path**: Make sure this points to the correct ImageNet label file. Otherwise, the output contains only class IDs.

### 4.4 Performance Monitoring

Enabling performance timing lets you analyze per-stage inference latency for performance tuning and bottleneck analysis.

**C++ example**:

```cpp
VisionServiceTimingOptions timing_options;
timing_options.enabled = true;
service->SetTimingOptions(timing_options);

VisionServiceResponse response;
service->Infer("test.jpg", &response);

VisionServiceTiming timing = service->GetLastTiming();
std::cout << "Preprocess: " << timing.preprocess_ms << " ms" << std::endl;
std::cout << "Inference: " << timing.model_infer_ms << " ms" << std::endl;
std::cout << "Postprocess: " << timing.postprocess_ms << " ms" << std::endl;
std::cout << "Total: " << timing.infer_ms << " ms" << std::endl;
```

**Performance optimization recommendations**:

- High preprocessing time: Image-classification preprocessing is relatively simple (resizing + normalization), so it should take little time.
- High inference time: Confirm that SpaceMITExecutionProvider is in use and check the thread-count setting.
- High postprocessing time: Postprocessing for classification consists only of softmax and sorting, so it should take very little time.

**Reference demo path**: `examples/resnet/`

## 5. Troubleshooting

- Enable timing: Use `SetTimingOptions` to view the duration of each stage.
- Inaccurate classification results: Confirm that the input image was preprocessed correctly (resized to 224×224).
- Mismatched labels: Confirm that `label_file_path` points to the correct `imagenet.txt`.

## 6. FAQ

| Symptom | Possible Cause | Resolution |
| --- | --- | --- |
| `Model file not found` | The model was not downloaded | Run `bash examples/resnet/scripts/download_models.sh`. |
| `No module named 'spacemit_vision'` | The wheel is not installed | Follow Section 2 to build the wheel, then run `pip install src/python/dist/*.whl`. |
| All classification results have low confidence | The input image is outside the ImageNet class set | Use a test image from the ImageNet class set. |
| Class IDs are output instead of names | The label file is missing | Confirm that `assets/labels/imagenet.txt` exists. |
