# V20260530

## Overview

V20260530 consolidates the major updates to the K3 ROS / SDK in May 2026. This phase focuses on completing the application loops for desktop robots, wheeled robots, robotic arms, and humanoid robots, and on strengthening on-device language interaction, sound source localization, visual inference, reinforcement learning policy execution, and navigation control capabilities.

This release is intended for developers who want to reproduce robot applications on the K3 platform, integrate on-device AI capabilities, and validate the motion control chain. Users can start from a reference solution to reach desktop robot, wheeled robot, robotic arm, or humanoid robot applications, or browse by topic such as AI and Algorithms, Robot Development, or System and Platform to find the corresponding components.

## Release Version

- **Release ID**: V20260530
- **Release or freeze date**: 2026-05-30
- **Recommended Git / SDK tag or branch**: Continuously updated open source, released simultaneously on GitHub and Gitee. The latest commit date for this release is 2026-05-30; refer to the manifest / repo release information for the specific branch or tag.
- **Key targets or product configurations**: K3 platform. Refer to the product engineering configuration and release manifest for specific targets.

## Updates

| Module or Domain | Description |
| --- | --- |
| Desktop robot | Completed the Reachy Mini application loop with new simulation control, component interface debugging, and one-click application startup, and added voice-controlled switching between face tracking and gesture tracking modes. |
| Robotic arm applications | Improved the LeRobot robotic arm application with Hermes Agent integration, allowing tasks to be triggered through natural language or tool calling. |
| Wheeled robot | Improved the Linksee wheeled robot application with new voice control capability, and fixed issues with RGB-D camera static transforms and motor feedback. |
| Humanoid robot | Improved humanoid robot simulation and reinforcement learning capabilities, with support for pre-policy chains and automatic gravity compensation computation in MuJoCo. |
| Model zoo | Enriched model zoo capabilities: a unified vision inference interface with simplified configuration; improved OpenAI tool calling compatibility for LLMs; standardized offline audio processing for ASR; quantized models by default for TTS with improved English phonemization; and voiceprint enrollment support. |
| Sound source localization | Added a DOA sound source localization component supporting dual-channel and multi-channel GCC-PHAT localization, C++ / Python interfaces, and a real-time microphone example, integrated into the Omni Agent application. |
| AI gateway | Improved the AI gateway with unified HTTP / WebSocket APIs for ASR / TTS / VAD / Vision / LLM / Embed / Rerank, on-demand model loading, standardized audio upload, model MD5 / URL metadata, and an improved front-end console experience. |
| Multimedia | MPP synchronized with the latest video, VI, and RTSP capabilities; Audio improved playback buffering and stream device handling. |
| Peripherals and control | IMU supports the ICM42670P INT1 interrupt; motors support parameter configuration, EtherCAT cyclic task priority, and RoHS idle handling; IO supports timestamps and interrupt events. |

**Upgrade recommendations**: Sync the latest repo / manifest and rebuild the SDK, then validate the robot reference solutions, AI gateway, sound source localization, audio/video chain, and peripheral control chain according to your actual use case. For the Linksee, Reachy Mini, LeRobot, or humanoid robot solutions, also check hardware connections, model files, launch parameters, and run scripts. For chassis or motor control, focus on validating motor feedback, static transforms, real-time task priority, and peripheral event reporting.
