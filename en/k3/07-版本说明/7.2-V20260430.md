# V20260430

## Overview

V20260430 consolidates the major updates to the K3 ROS / SDK in April 2026. This phase adds support for desktop robot, wheeled robot, humanoid robot, and robotic arm case applications, and further enriches the SDK's fundamental capabilities such as robot perception, motion control, localization and navigation, and path planning.

This release is intended for developers who want to reproduce complete robot solutions on the K3 platform, validate on-device AI capabilities, and integrate foundational robot packages. Users can start from a reference solution to reach a specific robot form factor, or browse by topic such as AI and Algorithms, Robot Development, or System and Platform to find the corresponding components.

## Release Version

- **Release ID**: V20260430  
- **Release or freeze date**: 2026-04-30  
- **Recommended Git / SDK tag or branch**: Continuously updated open source, released simultaneously on GitHub and Gitee. The latest commit date for this release is 2026-04-30; refer to the manifest / repo release information for the specific branch or tag.  
- **Key targets or product configurations**: K3 platform. Refer to the product engineering configuration and release manifest for specific targets.

## Updates

| Module or Domain | Description |
| --- | --- |
| Desktop robot | K3 now supports the Hugging Face open-source Reachy mini desktop robot, with fully local voice conversation, voice control, object tracking, and face tracking. |
| Robotic arm applications | K3 now supports the Hugging Face open-source LeRobot robotic arm, with hermes-agent and openclaw startup control actions. |
| Wheeled robot | Added the open-source "Zhixing" robot solution, covering a wheeled chassis combined with a robotic arm and providing mapping and navigation, motion control, and path planning capabilities. |
| Humanoid and quadruped robots | Added support for Unitree R1 / G1 and the Go1 robot dog, as well as on-device inference to simulation applications for platforms such as the Shanghai humanoid Qinglong and the Beijing humanoid Tiangong. |
| Model zoo | Enriched the model zoo with new voiceprint recognition and reinforcement learning model examples. |
| AI gateway | Added an AI gateway that exposes HTTP / WebSocket interfaces, allowing users to route calls to model capabilities directly. |
| AI Lab | Added AI Lab, a visual interactive model experience supporting both online cloud-based and local model evaluation. |
| Robot fundamentals | Enriched the fundamental capabilities for robot perception, motion control, localization and navigation, and path planning, supporting the reproduction of more robot solutions and secondary development. |
| Documentation | Refined the K3 documentation structure, covering Platform Overview, Quick Start, Reference Solutions, AI and Algorithms, Robot Development, System and Platform, and Release Notes. |

**Upgrade recommendations**: Sync the latest repo / manifest first, confirm the target and product engineering configuration, then rebuild the SDK. When reproducing robot cases, prepare the hardware, models, peripherals, and run scripts according to the corresponding reference solution first. When upgrading images, system components, or peripheral drivers, keep the previous image and engineering configuration available for rollback validation.
