# V20260330

## Overview

V20260330 consolidates the major updates to the K3 ROS / SDK from February to March 2026. This phase focuses on completing the robot AI capability stack, covering voice interaction, large language model inference, visual perception, and AI agents, while also providing unified wrappers for commonly used robot peripheral interfaces to reduce the cost of upper-layer application development and secondary integration.

This release is intended for developers using the K3 platform for AI capability validation, robot application development, and peripheral integration. With this version, users can quickly experience speech recognition, speech synthesis, VAD, large language model conversation, visual detection and recognition, agent tool calling, and access to common peripherals.

## Release Version

- **Release ID**: V20260330
- **Release or freeze date**: 2026-03-30
- **Recommended Git / SDK tag or branch**: Continuously updated open source, released simultaneously on GitHub and Gitee. The latest commit date for this release is 2026-03-26; refer to the manifest / repo release information for the specific branch or tag.
- **Key targets or product configurations**: K3 platform. Refer to the product engineering configuration and release manifest for specific targets.

## Updates

| Module or Domain | Description |
| --- | --- |
| Voice interaction | Provides unified C++ / Python interfaces supporting ASR speech recognition, TTS speech synthesis, and VAD voice activity detection. |
| LLM inference | Provides a unified application interface supporting the OpenAI API, multi-turn conversation, and tool calling. Validated with 10+ quantized models including Qwen2.5 / Qwen3, GLM-Edge, and DeepSeek R1. |
| Visual perception | Provides a unified vision application interface supporting YOLOv8 / YOLOv11 object detection, ByteTrack / OC-SORT tracking, YOLOv8-Pose pose estimation, and ArcFace face recognition, along with application examples such as emotion, fire, intrusion, and fall detection. |
| AI agent | Provides omni_agent, an out-of-the-box end-to-end voice interaction example integrating a standard MCP protocol client with support for stdio / Socket / HTTP transports, dynamic service discovery, and function calling. |
| Peripheral drivers | Unified wrappers for peripheral interfaces including IMU, light sensors, LiDAR, motors, buttons, NFC, and audio/video capture and playback. |
| Development tools | Unified SDK build system supporting one-click compilation of example applications, facilitating secondary development and component integration. |

**Upgrade recommendations**: First-time K3 SDK users are advised to complete source synchronization, environment initialization, and one-click SDK compilation first, then validate voice, vision, LLM, agent, and peripheral capabilities one by one. Users with existing projects are advised to sync the latest repo / manifest, rebuild the relevant components, and prioritize validating the peripherals, model files, and run scripts they depend on.
